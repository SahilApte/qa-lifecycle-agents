TestCase Generator
#3

Phase 3 — Execution
🎮
Executor Agent
#5
Uses Playwright MCP to navigate your application, execute test steps, and mark outcomes as Pass/Fail/Blocked. Checks dev PRs for blocked scenarios.
Requires Playwright MCP
🔧
Suite Optimizer
#6
Analyzes test plans to find duplicate scenarios, coverage gaps, and priority imbalances. Suggests additions and removals for an optimal test suite.
Fully Operational
Phase 4 — Automation
💻
Script Writer
#7
Generates Java Selenium code with Page Object Model, reusable methods, correct locators, TestNG, and proper coding standards — ready to run.
Fully Operational
🧬
Self-Healer
#8
Automatically heals broken locators in automation scripts by navigating the live application and capturing real DOM elements via Playwright MCP.
Requires Playwright MCP
